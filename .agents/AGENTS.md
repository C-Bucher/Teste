# Regras de Desenvolvimento - TechConnect 2.0

## Regras de Workflow e Desenvolvimento

- **Aprovação Prévia de Planos e Análises de Grande Porte**:
  Antes de efetuar alterações significativas no código do sistema (como novas telas, fluxos de pagamento, refatoração de frontend e preparação/migração de banco de dados), o assistente DEVE:
  1. Realizar levantamento detalhado de erros, gargalos futuros e melhorias necessárias.
  2. Apresentar o documento `implementation_plan.md` contendo a arquitetura proposta e os componentes envolvidos.
  3. Aguardar a autorização explícita do usuário antes de iniciar as modificações.

# Nota da pasta docs

**Função:** Documentação do projeto: requisitos, arquitetura, backlog (pendências), registro de alterações, decisões, reuniões e planejamento.

## O que tem aqui

- `arquitetura.md`: Documento: Documento de Arquitetura de Software (DAS) — TechConnect 2.0.
- `BACKLOG.md`: Documento: Backlog — TechConnect 2.0.
- `decisoes/`: ADRs (registros de decisão de arquitetura): cada arquivo explica uma escolha técnica importante e o motivo.
- `planejamento/`: Documentos de planejamento: plans (como fazer) e specs (o que fazer), organizados por data.
- `registro-de-alteracoes-para-documentacao.md`: Documento: Registro de Alterações — TechConnect 2.0.
- `requisitos.md`: Documento: Especificação de Requisitos do Sistema — TechConnect 2.0.
- `reunioes/`: Atas das reuniões da equipe e o modelo para novas atas.
- `mapa-do-frontend.md`: Documento: Mapa do frontend.
